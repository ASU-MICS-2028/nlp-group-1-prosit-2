# Docs

Documentation and decisions for the project.

| File | What it is |
|---|---|
| [PLAN.md](PLAN.md) | The tasks in order: owner, what each one needs first, status, and what "done" means. The README's Status section is generated from it |
| [decisions/](decisions/README.md) | One numbered record per decision (ADR): context, options considered, decision, consequences. The index is generated |
| `meetings/` | One summarized file per group meeting (`YYYY-MM-DD.md`). Never raw transcripts |

The repo is the source of truth for tasks and decisions. The older Drive plan doc (`NLP-GROUP-1/prosit 2/`) is out of date and points here; its product, architecture and evaluation sections are still useful background.

## Meeting summary format

```
# Meeting YYYY-MM-DD
Present: <first names>

## Decided
- <decision> (and its new record in docs/decisions/)

## Action items
- [ ] <who>: <what>, by <when>

## Discussed, not decided
- <topic>: <the options, who is checking what>
```
