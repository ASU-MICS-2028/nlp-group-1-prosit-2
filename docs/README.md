# Docs

Documentation and decisions for the project.

| File | What it is |
|---|---|
| [PLAN.md](PLAN.md) | The tasks in order: owner, what each one needs first, status, and what "done" means. The README's Status section is generated from it |
| [DECISIONS.md](DECISIONS.md) | Every decision we make, with the options considered and why. One line each, newest first |
| [CONTRACTS.md](CONTRACTS.md) | Suggested interfaces between the parts (tools, events, project layout, benchmark format, CLI). Suggestions only: each owner decides and documents the real one |
| `meetings/` | One summarized file per group meeting (`YYYY-MM-DD.md`). Never raw transcripts |

The design plan (product, architecture, evaluation) is the team doc on the shared Drive: `NLP-GROUP-1/prosit 2/Prosit 2 Plan - NLP Group 1`. The repo is the source of truth for tasks and decisions. When something is decided on the Drive, log it in `DECISIONS.md` too, because coding assistants can only read the repo.

## Meeting summary format

```
# Meeting YYYY-MM-DD
Present: <first names>

## Decided
- <decision> (also logged in DECISIONS.md)

## Action items
- [ ] <who>: <what>, by <when>

## Discussed, not decided
- <topic>: <the options, who is checking what>
```
