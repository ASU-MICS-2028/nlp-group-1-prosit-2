# 0011. Each person owns a workstream outside their strengths

- Status: Accepted
- Date: 2026-10-20
- Decided by: Joseph

## Context

Prosit 2 is meant to be a learning experience.

## Options considered

- Assign each workstream to whoever is strongest at it.
- Assign each person to work they are not already strong at.

## Decision
