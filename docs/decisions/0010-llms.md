# 0010. Claude Opus 5.5 as the main model, local Qwen 3.5 9B compared against it

- Status: Accepted
- Date: 2026-10-20
- Decided by: Joseph

## Context

The brief does not name a model. We need one strong enough to build working backends, and the choice has to be justified in Section B.

## Options considered

- Hosted API only.
- Local model only.
- Both: hosted as the main engine, local as a comparison.

## Decision

`claude-opus-5-5` through the Anthropic API is the main engine. Qwen 3.5 9B (4-bit GGUF, run with llama.cpp, file in the git-ignored `models/`) is run on the same tasks for comparison. Setup in `knowledge/environment.md`.

## Consequences

- Tested Oct 20: the Claude key works; Qwen makes correct tool calls at about 5 output tokens per second on an Apple M3.
- Hosted runs cost money; local runs are slow.
- The comparison (quality, time, cost, data staying on the machine) is a Section B result and material for Section A topic k.
