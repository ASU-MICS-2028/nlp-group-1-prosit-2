# 0008. Three shared folders: docs, learnings, knowledge

- Status: Accepted
- Date: 2026-10-20
- Decided by: Joseph

## Context

Teammates and their coding assistants do not have Joseph's notes, recordings or workspace. Everything needed must be in the repo.

## Options considered

- One folder of notes.
- Personal notes kept outside the repo.
- Three folders with separate purposes.

## Decision

`docs/` for the plan, decisions and suggested interfaces; `learnings/` for what each person found, simplified; `knowledge/` for everything people and coding assistants need about the project.

## Consequences

- Anyone can get up to speed from the repo alone.
- Each kind of information has one obvious home.
