# 0016. Decisions are recorded as numbered ADRs, one file each

- Status: Accepted
- Date: 2026-10-22
- Decided by: Joseph

## Context

One shared table of decisions became hard to read: long rows, and no room for the context or the consequences.

## Options considered

- One table in `docs/DECISIONS.md`.
- One file per decision (architecture decision records), numbered.

## Decision

Every decision is a numbered file in `docs/decisions/`, written from `0000-template.md`. Decisions 0001–0015 were moved from the old table on Oct 22.

## Consequences

- Each decision has its context, the options considered and the consequences, and can be linked by number.
- A changed decision gets a new record, and the old one is marked `Superseded by NNNN`, so history is never lost.
- The index in `docs/decisions/README.md` is generated.
