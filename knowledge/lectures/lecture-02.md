### Key ideas, explained simply
- **Datasets.** The university's local-language dataset is good for speech, weak for language modeling: its text is repetitive, like the Bible (which students should avoid). UG datasets cover 4 to 5 languages. Speech data comes with transcriptions, so keep only the text. Concatenating datasets is a good idea, but mixed sources add complexity. Aim for at least a few thousand sentences; about 28,000 was called "fairly good". It helps if a group member knows the language.
- **Colab workflow.** Set a constant like `PERCENTAGE = 0.05`, run the whole pipeline on that 5% sample to catch errors, then move to a GPU and set it to 1. Colab data disappears when the session ends, so mount Google Drive, download once into Drive, and comment out the download cell.
- **N-grams.** A bigger N is like adding neurons: more fluent, but needs more data. A 4-gram uses the 3 previous words. N-grams are Markov chains applied to language. Suggested path: bigram, then trigram.
- **Worked example (blocks in a bucket).** Unigram: random single words ("I Togo book leg"). Bigram: the next block must start with the last word, so "I live" can become "I live TV", because only "live" is the context. Trigram: the next block must start with "I live", so the result makes more sense.
- **No context.** A beginning-of-sentence token is added to training sentences; the model learns what usually follows it.
- **Grammar.** The simplest check is "is the word in the vocabulary?" Beyond that, "they is dancing" is rare in a corpus compared with "they are dancing", so it gets a very low probability and is flagged.
- **Hyperparameters.** Parameters (weights) are learned from data. Hyperparameters (width, depth/layers, learning rate, N) are chosen by you and tuned by trial. Judge output by reading it first, later with perplexity.
- **Sentiment vs tone.** Sentiment is the feeling (positive, sad). Tone is style (formal vs informal).
- **Embeddings.** Tokens get numeric IDs; since one number says little, a word is then represented by a vector (embedding).
- **Tokenizers.** They split text differently. That is fine if you use one tokenizer consistently all the way through.
- **Attention** is a technical term for neural networks only. For n-grams, say "context".
- **Stochastic parrots.** Stochastic means probabilistic, not deterministic. Models repeat what they saw, randomly, which looks like intelligence. Whether they are creative is a philosophical debate.
- "Language model" is the umbrella; LLMs are one kind, n-grams are the non-LLM kind.

## Likely quiz or viva questions
1. **Parameter vs hyperparameter?** Parameters are learned from data; hyperparameters (width, depth, learning rate, N) are chosen and tuned.
2. **Why can a bigram give "I live TV"?** It only conditions on "live"; a trigram conditions on "I live".
3. **How does a model start with no context?** With a beginning-of-sentence token.
4. **How do probabilities flag bad grammar?** Rare phrases like "they is" get very low probability.
5. **Does tokenizer choice matter?** Not if one tokenizer is used consistently throughout.
6. **How are Sections B and C submitted?** Each student submits their own document; B and C are identical across the group.
